개인정보처리방침 초안

출시 전 검토용 문서입니다. 2026년 11월 16일 현재 개발 버전의 기능을 기준으로 작성했습니다. 외부 서비스의 위탁·국외 이전 관련 사항, 처리의 법적 근거와 최종 시행일을 확정한 뒤 정식 방침으로 게시할 예정입니다.

운영자 김형진은 닙키(NibKey)의 개인정보 처리 방식을 다음과 같이 안내합니다. 기존 테스트 버전은 Margin이라는 이름으로 표시될 수 있습니다.

1. 앱에서 작성하는 내용

노트의 제목과 본문, 수식, 필기, 가져온 PDF와 이미지, 녹음 및 기록 시점 정보는 노트 편집·열람·재생을 위해 기기 내 앱 저장 공간에서 처리됩니다. 현재 앱에는 회원가입 기능이나 운영자가 노트 내용을 수신하는 서버 전송 기능이 없습니다. 광고·행동 분석용 SDK와 외부 AI 전송 기능도 현재 구현에는 포함되지 않습니다.

글쓰기 환경, 펜 설정, 마지막 사용 문서와 백업 내보내기 시각 등은 사용 편의를 위해 기기에 저장됩니다. 시스템의 기기 백업 설정에 따라 앱 데이터가 Apple 등의 기기 백업에 포함될 수 있습니다.

2. 사진·파일·마이크·붙여넣기

사진과 파일은 시스템 선택 화면에서 사용자가 선택한 항목을 가져옵니다. 붙여넣기를 실행하면 클립보드의 텍스트나 이미지를 노트에 넣을 수 있습니다. 녹음 기능은 마이크 권한을 허용한 뒤 사용하며, 녹음 파일은 해당 노트와 함께 기기에 저장됩니다. 마이크 권한은 iPad 설정에서 변경할 수 있습니다.

3. 백업과 데이터 삭제

사용자가 백업 내보내기를 실행하면 서재의 노트·첨부파일·녹음·저장 복구본을 하나의 파일로 만듭니다. 파일 앱에서 iCloud Drive 또는 다른 저장 위치를 직접 선택합니다. 이 기능은 실시간 동기화나 자동 클라우드 백업 기능이 아닙니다. 클라우드에 저장하면 해당 서비스 제공자의 약관과 개인정보 처리방침이 적용됩니다.

삭제한 노트는 ‘최근 삭제한 항목’에 남아 있으며 사용자가 영구 삭제할 때 앱의 해당 항목을 제거합니다. 현재는 자동 만료되지 않습니다. 수정하거나 개별 녹음을 삭제한 후에도 이전 내용이 저장 복구본에 남을 수 있습니다. 정상 저장 복구본은 최근 최대 3개를 유지하도록 관리됩니다.

기기에서 앱 자체를 삭제하면 앱의 로컬 데이터가 제거되지만, ‘앱 정리하기’는 데이터를 보존할 수 있습니다. 이미 내보낸 백업, 원본 PDF·사진, 다른 기기에 있는 사본과 기기 백업은 별도로 관리·삭제해야 합니다. 개발자는 사용자의 기기나 개인 클라우드에 있는 파일을 원격으로 삭제할 수 없습니다.

4. 테스트 진단 정보

현재 개발 버전에서 사용자가 진단 메뉴로 테스트 노트를 만들면 입력 문제를 확인하기 위해 해당 테스트의 입력 원문, 조합·삭제 이벤트, 커서와 선택 범위, 문서·페이지 식별자, 시각, 앱 버전 및 선택한 입력 방식이 기기에 기록될 수 있습니다. 일반 노트에 대한 진단은 기본으로 켜지지 않습니다.

진단 로그는 자동으로 개발자에게 전송되지 않습니다. 현재 로그는 앱 저장 공간에 별도로 남으며, 테스트 노트를 삭제하는 것만으로 함께 삭제되지 않습니다. 앱 자체를 삭제하면 로컬 로그도 제거되지만 기기 백업의 사본은 별도로 관리해야 합니다. 로그를 개발자에게 보내는 경우에는 개인적인 내용을 확인하고 필요한 부분만 보내주세요.

5. 이메일 문의

문의 주소는 nibkeyapp@gmail.com입니다. 문의를 보내면 발신 이메일 주소, 표시 이름(있는 경우), 문의 내용, 선택적으로 보낸 기기·앱 버전 정보와 첨부파일을 답변 및 오류 해결을 위해 처리합니다. 문의를 보내지 않아도 앱의 노트 기능을 이용할 수 있습니다.

문의 내역은 처리 완료 후 1년 이내 삭제합니다. 삭제할 때 메일과 내려받은 첨부 사본을 제거하고 메일 휴지통도 비웁니다. 법령에 따라 보관해야 하는 경우에는 해당 항목과 근거, 기간을 별도로 안내합니다. 서비스 제공자가 관리하는 백업 등의 삭제 시점은 해당 제공자의 정책에 따릅니다.

6. 외부 서비스와 웹사이트

문의 이메일은 Google의 Gmail을 사용합니다. 메일 전송·보관 과정에서 Google이 이메일과 첨부파일을 처리하며, 국외에서 처리될 수 있습니다. 상세한 서비스 처리 내용은 Google 개인정보처리방침에서 확인할 수 있습니다.

안내 웹사이트는 GitHub Pages에 게시됩니다. 사이트에 별도의 광고, 방문 분석 코드, 입력 폼 또는 추적 쿠키를 넣지 않았습니다. 다만 호스팅 제공자인 GitHub는 접속 IP 등 기술 정보를 처리할 수 있습니다. GitHub 개인정보처리방침을 참고하세요.

App Store·TestFlight 및 운영체제의 진단 정보 처리는 Apple의 서비스와 사용자 설정에 따릅니다. Apple 개인정보 안내에서 확인할 수 있습니다. 본 문서의 외부 서비스 링크만으로 위탁·국외 이전에 관한 고지가 완성되는 것은 아니며, 관련 세부 사항은 정식 방침 확정 전에 보완합니다.

7. 열람·정정·삭제 및 문의

운영자에게 보낸 문의 정보에 대해 열람·정정·삭제·처리 정지 등을 요청하려면 아래 이메일로 연락해주세요. 요청 처리에 필요한 범위에서 본인 확인을 요청할 수 있습니다. 기기에만 저장된 노트 내용은 개발자가 보유하지 않으므로 앱과 개인 백업에서 직접 관리할 수 있습니다.
